# P6-A：销售订单与合同联动

版本 0.18.0。企业成员在左侧「交易与交付 → 销售订单」操作；复用现有合同读写及客户范围权限，平台运营和只读支持授权不能处理订单。

## 功能与操作

1. 销售从尚未用于订单或合同的有效、已批准报价创建订单草稿。系统复制报价版本、产品明细、成本与成交额快照，生成企业内唯一订单编号；同一报价版本只能转换一次，请求编号支持安全重试。
2. 草稿可改主题、交期和备注，不能改批准报价的价格或产品。确认时再次核验报价批准记录及当前折扣、毛利规则；若规则收紧，应重新报价、审批并创建新订单。
3. 确认后可登记各行累计履约数量；不得倒退、重复行或超过订购数量，订单状态自动变为「已确认／部分履约／已履约」。草稿或未履约且未关联合同的确认订单可填写原因作废，留存历史。
4. 在订单详情建立合同，金额取订单关联报价，生成一期收款计划；再到「合同管理」拆分期次、签订、生效和回款。订单详情可打开关联的合同。
5. 已关联订单的合同受控变更不得单独改变金额、产品组合、数量、单价或折扣；期限、备注和同额分期仍受原合同版本、经理权限、已收款约束。旧合同没有强制补录订单，可沿原入口继续操作。

## 数据与安全

- Flyway V22 增加订单编号计数、订单、订单行、订单事件，四表均强制租户 RLS；合同增加同企业、同客户的可选订单外键和单订单至多一份合同的唯一约束。
- 订单 API：`GET/POST /api/v1/sales-orders`、`GET /sales-orders/quote-options`、`GET/PUT /sales-orders/{id}`、`POST /sales-orders/{id}/confirm|void`、`PUT /sales-orders/{id}/fulfillment`、`GET /sales-orders/{id}/history`。创建合同继续使用 `POST /contracts`，可携带 `orderId`。
- 使用现有登录、工作区、CSRF、订阅状态、客户与商机可见范围、合同角色范围；成本仅向具备产品写权限的成员展示，事件保留版本和操作人。
- 报价一旦用于订单，即保留其历史商业依据，不能直接作废或重新修改该报价。金额以整数分存储，数量精度四位小数。

## 验收步骤

1. 销售经理配置产品成本与毛利规则；销售创建报价，由另一位销售经理审批，在销售订单中选择批准报价并保存草稿。
2. 重复转换同一报价、越权选择另一企业客户、过期报价、同一请求编号不同内容，均应拒绝；草稿确认后再次转换也应拒绝。
3. 录入部分履约，再录入全部履约；尝试倒退、超量、漏行、错误版本应拒绝。历史中应看到操作人和版本。
4. 从已确认订单建合同并检查订单、合同、收款计划金额一致；重复建立应拒绝。尝试用不同金额的新报价单独变更关联合同应拒绝。
5. 用只读成员、销售本人/团队范围及另一个企业复核订单可见性和操作权限。
