# P5-B 开发交付：线索与客户资源池

## 本阶段范围

在企业端左侧导航增加“线索池”和“客户资源池”。资源池分别展示可领取资源、我负责的资源；具备全局写入权限的销售经理或企业管理员还可查看团队资源、单条派发及按页批量分配。池内资源从常规线索、客户列表隐藏，领取或派发后回到对应工作区。

操作包括领取、退回、派发、最多 50 条的批量分配、按规则回收、停用成员时的资源转交和历史查询。企业管理员可在资源池页面手动触发一次超期检查，定时任务在启用 `CRM_RESOURCE_SCHEDULE_ENABLED=true` 时每小时运行；留存阈值沿用“销售资源规则”中的线索和客户未跟进天数。客户存在进行中的商机、有效合同、未关闭服务工单或待办时不回收。

所有变更在同一数据库事务里检查租户、角色、接收成员、保有量及记录版本；领取和批量分配持有企业级锁与资源行锁，重复领取及过期版本会返回冲突，批量请求遇到冲突整批回滚。操作写入资源流转历史；人工操作同时写入审计日志。停用成员时，在同一事务中转交其在手的活跃线索和客户，若接收人权限或额度不足则成员停用也回滚。

## 操作入口

| 使用人 | 入口 | 可以操作 |
| --- | --- | --- |
| 销售成员 | 客户企业端 → 左侧“线索池 / 客户资源池” | 查看可领取资源、领取、退回自己负责的资源、看流转记录 |
| 销售经理或企业管理员 | 同上 → “团队资源” | 查看团队资源、派发、批量分配、退回、看历史 |
| 企业管理员 | 同上 → “检查超期资源”；左侧“组织成员”编辑成员 | 手动回收超期资源；停用成员时选择接收人 |
| 企业管理员 | 左侧“销售资源规则” | 设置保有量与超期天数；定时回收按此规则执行 |

旧记录初始保持原负责人且不入池。可以从“我负责的资源”或“团队资源”手动退回资源池；到达设定的未跟进期限后自动回收。转换完成或不合格线索不参与资源池分配与自动回收。客户回收到池中时移除原共享关系。

## 技术变更与验证

- 数据库迁移：`V19__resource_pools.sql`，为线索和客户增加池状态、入池及分配时间，新增隔离租户的资源流转表。
- 服务与接口：`ResourcePoolService`、`ResourcePoolController`；`/api/v1/resource-pool/{leads|customers}` 提供查询、领取、退回、派发、批量分配、接收成员、历史；`/api/v1/resource-pool/recover` 提供管理员手动回收。
- 界面：`ResourcePoolWorkspace.vue`、企业端左侧导航、成员停用接收人选择。
- 本地前端：`npm run build` 和 `npm test`；云端后端：Maven 编译、测试与 Flyway 迁移，以发布日志和健康接口为准。
