## 证书核验

用户提供的 Nginx 证书压缩包已在临时目录完成核验：

- 证书覆盖 crm.jiayunsoft.com 与 www.crm.jiayunsoft.com。
- 有效期为 2026-10-22 00:00:00 UTC 至 2027-01-19 23:59:59 UTC。
- 证书公钥与私钥匹配。
- 证书与私钥不加入 GitHub 仓库，也不加入公开下载包。

部署时将完整证书链放到 `/etc/nginx/ssl/binbin-crm/fullchain.pem`，私钥放到
`/etc/nginx/ssl/binbin-crm/privkey.pem`，目录由 root 管理，私钥权限 0600。
不能使用系统时钟错误或证书验证关闭的方式绕过 TLS 校验。

## 服务器检查与部署顺序

1. 执行 `sh server/ops/vm/check_host.sh`，核实内存、磁盘、端口、Docker、已有站点和 DNS。
2. 使用完整仓库的独立预览容器方案，创建独立的 PostgreSQL、对象存储、网络和数据卷。
   不复用现有业务数据库，也不停止现有业务容器。
3. 将应用 origin 设为 `https://crm.jiayunsoft.com`，Secure Cookie 开启，
   `CRM_ISOLATED_ACCEPTANCE=false`，AI 总开关保持关闭。
4. 应用只绑定 `127.0.0.1:18080`，不向公网发布数据库或对象存储端口。
5. 在核实内存余量后决定容器资源上限；小内存服务器不要同时编译全部镜像。
6. 使用 `server/ops/vm/crm.jiayunsoft.com.conf` 添加独立虚拟主机。
   修改前备份已有配置，检查站点重名与 80/443 的占用情况。
   `nginx -t` 成功后才允许 reload；不能覆盖整个 Nginx 配置目录。
7. 核实域名 DNS 指向本机，依次验证本机健康接口、外网 HTTPS、登录、租户权限和附件。
8. 记录实际版本、数据库迁移版本、容器重启后的持久化结果与回滚路径。

## 预览范围

独立预览包含虚构测试企业与客户数据；不自动迁入旧云环境中的业务数据。
现有独立容器方案中的内部 CA 和服务证书有效期为 30 天。
对象存储镜像为测试用固定版本，因此这一方案用于短期预览，正式运营需更换维护中的存储服务，
落实备份恢复、证书续期、独立密钥保管、正式邮件服务与客户试点。

## 2GB Ubuntu 主机的预编译部署包

`Package Ubuntu CRM preview` 工作流在云端编译应用、PostgreSQL 初始化工具和测试存储镜像，
将精确的镜像 ID、SHA-256 与完整跟踪源码打包。服务器无需安装 Java、Node、Maven 或 Go 来编译。
包中不包含登录密码、数据库密码、任何私钥或用户的域名证书；首次启动时在服务器本地生成随机凭据。
报价 PDF 所需的中文字体在 CI 中按固定来源与 SHA-256 生成，随包提供 SIL OFL 授权，
安装时仅向该预览的私有存储发布固定字体资产，并校验 HTTPS 回读；不改写业务记录。

已提供的服务器检查显示：物理内存 1967 MiB、可用内存约 1346 MiB、无 Swap，根分区可用约 18GB。
现有 sub2api、PostgreSQL 17 和 Redis 容器，以及现有 Nginx 和 Python 服务均保留。
新 CRM 应用的内存上限为 1GiB，专用 PostgreSQL 与测试存储各 256MiB，初始化工具另有限额。
这适合低流量的短期预览；尚未进行该主机的容量或正式客户负载验证。

使用 `--create-swap` 时，安装器为小内存主机创建 `/swapfile-binbin-crm`（2GiB、0600），
先备份现有 `/etc/fstab`，再追加本文件的开机挂载项，不调整现有 Swap。
已有同名文件但无法确认状态时会停止，避免覆盖。

将工作流输出的 `binbin-crm-vm-0.23.0.tar.gz` 和用户原始证书 ZIP 上传到服务器 `/root` 后，
先核对交付时给出的外层 SHA-256，再执行：

```bash
test ! -e /opt/binbin-crm-preview && tar -xzf /root/binbin-crm-vm-0.23.0.tar.gz -C /opt
python3 /opt/binbin-crm-preview/project/server/ops/vm/install_vm.py --cert-zip /root/28013636_crm.jiayunsoft.com_nginx.zip
python3 /opt/binbin-crm-preview/project/server/ops/vm/install_vm.py --cert-zip /root/28013636_crm.jiayunsoft.com_nginx.zip --apply --create-swap
```

第一条安装器命令只校验包和证书。第二条明确开始部署。重复安装不得覆盖已有部署目录；
同一包的中断安装可直接重跑安装器，已有密码和卷保留。
镜像标签由源码提交确定，加载后还会核实完整镜像 ID；Compose 使用 `--no-build --pull never`。

用户需在 DNS 管理中添加 `crm` 的 A 记录到 `45.205.28.7`，并确保安全组允许既有的 80/443。
安装器只添加独立的 `binbin-crm.conf`，本地以正确域名与系统信任库验证 HTTPS，
不把该检查视为外网访问已成功。外网解析和实际访问须另行验证。
若已存在同域名站点或不同的证书配置，安装器会停止，不覆盖。

初始企业管理员为 `owner`，初始密码仅存放在服务器
`/opt/binbin-crm-preview/project/.crm-preview/secrets/login_password`，由服务器管理员在本地读取。
其他虚构演示账号共用此初始密码，因此不要在短期预览中导入真实客户敏感数据。
旧云环境的数据不会自动迁入；正式启用 DeepSeek 前需要替换旧供应商密钥。
