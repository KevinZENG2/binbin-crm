## 使用路径

- `owner`：已有企业的管理员兼销售经理，可体验客户、成员、部门、角色权限、订阅、支持授权与企业管理记录。
- `tech-admin`：企业管理角色，无默认客户业务权限。
- `alice` / `bob`：销售业务身份；`viewer`：只读身份。
- `platform-operator`：平台运营，可管理企业 / 套餐、审核人工续费、重置账号密码、查看操作记录。读取企业客户必须先获得该企业管理员的明确授权。

以上既有测试账号密码沿用此前交付，不写入源码或前端。新开通的管理员和新建成员必须先修改初始密码。当前创建新成员会建立新的全局登录账号；尚未提供邀请邮件和将已有账号加入另一个企业的流程。

人工续费路径：企业管理员提交 1 / 3 / 6 / 12 个月申请，服务端固定当时的套餐和整数分金额；运营核实收款并填写凭据编号后确认。从当前有效期和当前时间的较晚者延长，按企业时区计算自然月，月底正确落到目标月末。同一申请重复确认只返回原结果。

支持路径：企业管理员选择运营账号、目的、1～4 小时有效期及可读字段；运营从获批支持列表进入只读客户工作区。授权到期或撤销后，后续请求立即拒绝。支持访问不能修改客户、成员、角色、订阅或共享，成功的列表 / 详情读取记录到独立访问日志。

## 后端接口

接口前缀 `/api/v1`。管理请求使用服务器认证会话、CSRF 和角色检查；当前企业由服务器会话决定，`X-Workspace-ID` 只用于检测页面工作区过期，不能用于取得其他企业权限。

|接口组|实现|
|---|---|
|`/platform/plans`|列表、创建、带版本编辑，月费整数分与额度校验|
|`/platform/tenants`|列表、创建企业及初始管理员，带版本调整套餐 / 状态|
|`/platform/renewals`|申请列表、`/{id}/decision` 确认或驳回|
|`/platform/accounts`|账号元数据、`/{id}/password-reset` 强制改密并撤销会话|
|`/platform/support/grants`、`/platform/support/{id}/enter`、`/platform/support/exit`|仅本人获批授权的支持工作区进入 / 退出|
|`/platform/audits`|管理元数据，不包含客户正文或密码|
|`/workspace/summary`|企业套餐、有效期、成员和客户实际计数|
|`/workspace/departments`|创建及带版本编辑；防循环，最多十层 / 一百个有效部门|
|`/workspace/members`|创建、带版本调整归属 / 角色 / 状态；成员额度与最后管理员保护|
|`/workspace/role-policies`|四种角色的客户对象、记录范围、字段权限配置|
|`/workspace/renewals`|创建、列表、`/{id}/cancel`；到期仍可申请续费|
|`/workspace/support/operators`、`/workspace/support/grants`|管理员创建 / 撤销授权，`/{id}/access` 查询访问记录|
|`/workspace/audits`|本企业管理动作|
|`/auth/password`|旧密码校验、自助改密，至少十二个字符且最多七十二个 UTF-8 字节|
|`/customers/{id}/shares`、`/customers/{id}/share-recipients`、`/customers/{id}/transfer`|限时共享、有效收件人、版本化转交|

创建资源使用 `Idempotency-Key`；修改使用 `expectedVersion`。客户端不能注入企业编号、账号权限或系统版本。

## 数据与实现

Flyway V2 新增套餐、部门、角色策略、续费申请、支持授权、支持访问记录、平台管理审计与管理幂等记录；企业增加套餐关联、版本与配额计数，成员增加部门与版本，账号增加首次改密标记。

额度写入先锁企业行，重新检查当前身份和用量，再提交业务变更。数据库触发器在同一事务中维护有效成员 / 客户计数，回滚同时撤销计数变化。新增幂等重放先识别历史结果，在额度已满时仍可返回之前创建的资源。套餐降额或企业切换套餐不能低于已用额度。

租户业务表由迁移角色拥有，运行角色无超级用户、BYPASSRLS 或表所有权。所有受范围保护的表强制 RLS；使用 `SET LOCAL` 设置事务企业上下文。配额触发器固定搜索路径并撤销 PUBLIC 执行权限。管理身份表和全局平台表由服务端明确鉴权，不能把它们表述为全部由 RLS 保护。

客户读取与写入范围分别组合多个角色，广泛读取不会自动扩大写入范围。字段不可见时由 API 隐藏，不仅是页面隐藏；禁止写入被保护字段，合法核心编辑保留未提交的隐藏字段。共享写入者不能再转授权；负责人或获允许范围的管理者才能管理共享和转交。

角色、成员状态、账号版本、企业状态和支持授权均在后续请求重新检查。密码、会话摘要与初始密码不写入返回值、平台审计或管理幂等请求摘要。审计保存操作者、动作、资源和追踪编号。
