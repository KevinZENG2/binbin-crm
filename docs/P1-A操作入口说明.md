# P1-A 操作入口

真实企业管理：https://crm-java-api-crm-test.up.railway.app/?account=owner

真实平台运营：https://crm-java-api-crm-test.up.railway.app/?account=platform-operator

链接只预填账号，仍需输入上一版交付的密码。若页面已有其他账号登录，会提示先退出再切换。旧标签页可按 Ctrl+F5 刷新。

## 企业管理员

使用 `owner` 登录，先在“当前企业”选择“星澜科技 · 测试企业”。登录后顶部导航和“企业管理入口”功能卡片包含：

|功能|入口|操作|
|---|---|---|
|成员管理|组织成员|创建成员、选择部门、授予角色、停用 / 恢复|
|部门结构|部门管理|新增或编辑部门、设置上级部门|
|客户记录与字段权限|角色权限|修改读取 / 写入范围、信用代码及备注权限|
|用量与续费申请|套餐订阅|查看成员 / 客户额度和有效期，提交续费|
|支持授权与访问记录|支持授权|选择运营账号和时限，授权 / 撤销，查看访问记录|
|企业管理审计|管理记录|查看本企业管理动作|
|客户共享与转交|客户中心 → 查看 / 编辑|弹窗下方共享和转交区域；按钮随实际权限显示|
|修改自己的密码|顶部账号区域 → 修改密码|校验旧密码；修改后旧会话失效|

新创建的账号首次登录会自动要求改密。会话撤销和数据库初始化修复是系统行为，没有独立操作菜单。

## 平台运营

使用 `platform-operator` 登录，进入“平台管理入口”：

|功能|入口|操作|
|---|---|---|
|开通企业、调整套餐、暂停 / 恢复|企业与订阅|开通企业或编辑订阅与状态|
|套餐价格与额度|套餐管理|创建 / 编辑月费、成员及客户额度|
|人工续费处理|续费审核|核实收款凭据后确认，或填写原因驳回|
|账号密码重置|登录账号|重置会撤销该账号旧会话，并要求下次改密|
|企业授权的只读支持|支持访问|进入仍有效的授权工作区|
|平台管理审计|操作记录|查看管理元数据|

企业管理员管理自己企业的成员和续费申请；套餐配置、企业开通和续费确认由平台运营执行。销售或只读账号不会显示企业管理入口。原 ChatGPT 域名首页保留浏览器流程演示，并提供上述两个真实管理链接。

## 客户弹窗

客户中心点击“查看 / 编辑”或“新增客户”，窗口固定在屏幕中间。内容较长时滚动弹窗中间的表单区域，底部保存 / 关闭按钮保留在窗口内；客户共享和转交位于表单下方。打开弹窗时背景页面停止滚动，关闭后恢复。已有页面可按 Ctrl+F5 获取更新。
