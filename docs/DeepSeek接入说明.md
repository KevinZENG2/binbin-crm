# DeepSeek 接入说明

本产品默认接入供应商选为 DeepSeek，当前已预留正式接口。没有真实 Key 时保持关闭。

## 产品方配置

1. 在服务器安全变量中填写 `CRM_AI_DEEPSEEK_API_KEY`，重新部署服务使配置生效；密钥不在客户页面录入。
2. 使用平台运营账号，在左侧「AI 模型与预算」添加 DeepSeek 模型，填写账号可用的模型标识、输入/输出人民币参考单价及单次输出上限。
3. 配置完成后再开启服务器总开关 `CRM_AI_ENABLED`。先用虚构资料做小范围真实调用验收，核对返回、脱敏及供应商用量账单。
4. 企业管理员在左侧「企业 AI 设置」选择模型，设置月 Token 预算、参考费用预算及请求频率，再启用本企业。

## 客户成员使用

从「AI 助手」选择权限范围内的业务记录，点击「预览脱敏内容」，确认实际发送内容、供应商及模型，勾选同意后生成建议。确认五分钟有效，修改资料或配置后重新预览。

当前提供摘要、商机建议和工单回复草稿。直接对 AI 说“新建李四线索”并创建记录，留待后续业务动作扩展；届时需先预览拟建记录、人工确认并检查权限，本轮不包含。

## 接口约定

正式地址 `https://api.deepseek.com/chat/completions`；Bearer 认证；使用 `messages`、`max_tokens`、`stream=false`。当前采用 `thinking.type=disabled`，模型名称可配置，不依赖某个固定版本。超时或结果无法确认时不自动重试，按预留用量保守计入参考预算。

参考费用依据平台人工输入单价，不是供应商发票或真实扣款上限。当前使用隔离合成接口验证软件流程；真实 DeepSeek 密钥与联网验收待后续接入。

官方依据：https://api-docs.deepseek.com/zh-cn/ 与 https://api-docs.deepseek.com/api/create-chat-completion/ 。
