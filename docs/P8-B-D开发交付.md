## 功能与入口

| 使用人 | 左侧入口 | 操作 |
|---|---|---|
| 企业销售、销售主管 | AI 助手 | 选择场景和当前可见资料，预览脱敏内容，确认后生成建议 |
| 企业管理员 | 企业 AI 设置 | 企业开关、模型、预算、敏感词和日期金额事实检查 |
| 产品方平台运营 | AI 模型与预算 | 模型参考价格、套餐预算、提示词版本、灰度发布、关闭及回滚 |

销售场景：客户经营摘要、商机推进建议、营销活动建议、线索研判、拜访准备、跟进记录草稿、新建线索草稿。

服务与管理场景：工单回复草稿、客诉与工单分诊、销售周报辅助、经营异常解释、报价审批辅助。

场景继续遵守原模块和记录权限。报价审批辅助仅供当前指定审批人使用，不批准或驳回报价。周报辅助不会提交周报；营销建议不会对外发送消息；工单建议不会修改 SLA 或工单状态。

## 受控业务保存

只支持新建线索和客户跟进记录两种类型化动作，不提供任意工具调用。

1. 生成前预览实际脱敏内容并确认，供应商调用继续遵守 P8-A 的预算、幂等及计费规则。
2. 模型返回草稿字段，用户逐项编辑；未知必填项需补齐，电话邮箱由用户自行填写。编辑后的业务字段不会再次发往模型。
3. 服务端保存待确认草稿，返回字段预览和五分钟单次确认。不会在此时创建业务记录。
4. 确认时重新核验成员权限、来源资料、提示词发布及企业敏感策略，再调用原业务服务。
5. 同一生成记录及成员只能保存一次；并发重试返回同一业务结果。取消后保留审计。

线索归属当前成员；跟进只允许保存至本次来源客户，实际互动时间由用户填写。原业务接口继续检查容量、关联对象、时间和写入权限。

## 质量与发布

- 提示词版本创建后不可修改。发布指针保存上一版本，可按企业固定分组灰度覆盖 0～100%，也可立即关闭。
- 原三个场景延续已有发布；新增九个场景默认关闭。产品方试点后逐个开放，不因升级自动产生付费调用。
- 企业敏感词用于本次发送和模型输出脱敏；命中敏感词的输出阻断采纳。策略变化后，未保存业务草稿须重新生成。
- 对来源未出现的日期、金额、比例和未确认的执行承诺标记待复核。规则检查不等于证明无幻觉。
- 主管复核记录结论、事实准确度、业务帮助度和核实依据；阻断结果不能通过主管采纳绕过。
- 每次调用记录权限指纹。字段权限或经营汇总范围变化后重新核验历史输出；缺少字段权限快照的旧结果仅显示说明，需重新生成。
- 输出即使被质量策略阻断，供应商调用的实际或保守估算费用仍正常结算，不虚假退回已发生的调用成本。
- 平台离线规则评估只检查人工编写的虚拟素材和输出，明确不调用供应商；真实模型准确度需接入 Key 后试点核验。
- 回滚只影响后续调用与未保存草稿，不撤销已保存的业务事实。

## 数据与接口

V30 新增平台提示词版本、发布指针，以及强制租户 RLS 的质量策略、复核评分、业务草稿表。AI 调用记录新增提示词、发布、策略和来源摘要哈希及检查结果。备份校验支持 V5～V30，旧版本备份仍可识别。

新增主要接口：

- `GET /api/v1/ai/tasks`、`GET /api/v1/ai/tasks/{task}/sources`
- `POST /api/v1/ai/runs/{id}/proposals`、`POST /api/v1/ai/proposals/{id}/confirm`、`POST /api/v1/ai/proposals/{id}/cancel`
- `POST /api/v1/ai/runs/{id}/review`、`GET /api/v1/ai/runs/{id}/evaluations`
- `GET/PUT /api/v1/ai/quality-settings`
- `GET/POST /api/v1/platform/ai/prompts`
- `PUT /api/v1/platform/ai/releases/{task}`、`POST /api/v1/platform/ai/releases/{task}/rollback`
- `POST /api/v1/platform/ai/rule-test`

写入继续校验 CSRF、当前企业、订阅状态和角色，不接受模型传入任意 API 地址或工具名称。
