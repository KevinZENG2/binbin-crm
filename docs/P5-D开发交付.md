# P5-D：商机预测与报价风控

版本 0.17.0。客户企业端左侧进入「商机与看板」和「产品与服务目录／客户报价」。平台运营端不处理企业业务数据。

## 本阶段交付

| 能力 | 操作方式与规则 |
| --- | --- |
| 商机产品明细 | 打开商机资料，在「产品／服务明细」搜索启用产品并添加数量、含税单价、折扣。保存后服务端逐行计分、汇总预计金额并更新商机版本；已有明细时不能直接在基本资料中改预计金额。重复产品、过期版本及已批准报价后的明细修改会被拒绝。移除全部明细使预计金额归零。 |
| 阶段准入 | 阶段仍只能相邻推进／回退，任意开放阶段可丢单。进入「方案讨论」及之后需先维护产品明细；进入「签约准备」或「成交」需该商机存在有效且已批准的关联报价。沿用报价的指定异人审批，审批版本和报价状态需一致；行业配置中停用的目标阶段不能进入。 |
| 加权预测 | 商机看板展示未来六个月按预计成交月份、阶段划分的原始金额、阶段概率与加权金额。概率来自现有「行业配置中心」商机阶段配置；只统计当前账号有权查看的未关闭商机，数值是预测而非承诺回款。 |
| 折扣与毛利 | 销售经理在「产品与服务目录」设置企业单行折扣上限和最低预计毛利率。报价草稿可先保存；提交审批时按报价行成本快照和含税成交金额重新核算，不合规则拒绝提交。审批请求保留当时规则版本与核算摘要。 |

## 数据与权限

- `V21__opportunity_forecast_and_pricing.sql` 新增商机明细表并强制租户 RLS；报价行新增成本快照，历史行迁移时按当时目录成本补齐（无法追溯更早的原始成本）。报价规则放在已有企业审批配置，默认单行最大折扣 30%、最低预计毛利 10%。
- 商机明细写入要求商机与客户可写且可读产品目录；报价规则修改要求产品目录写权限。预测基于现有商机、客户及负责人范围权限查询，不跨企业。
- 接口：`GET/PUT /api/v1/opportunities/{id}/lines`、`GET /api/v1/opportunities/forecast?from=YYYY-MM-01&to=YYYY-MM-01`、`GET/PUT /api/v1/pricing-policy`。写入使用现有会话、CSRF、订阅状态和版本校验。报价仍走现有提交和异人审批接口。

## 验收路径

1. 销售经理维护产品售价与成本，并在产品目录设置折扣与毛利规则；销售打开商机，添加明细，核对预计金额与版本。
2. 不维护明细直接推进到方案阶段应被拒绝。添加明细后可推进；无已批准关联报价时进入签约准备应被拒绝。指定其他销售经理审批报价后重试应可通过。
3. 调高折扣或降低售价使报价不满足规则，草稿保存可成功，提交审批应给出具体原因；调整后重新提交，审批快照保留规则。
4. 在行业配置中心调整阶段概率，再回到商机看板检查可见范围内的加权预测；用只读成员与其他企业分别复核写入限制和数据隔离。

## 后续
