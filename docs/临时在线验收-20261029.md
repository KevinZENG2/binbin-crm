# 临时在线验收

2026-10-29。用户要求先使用云端线上版本，不部署到其服务器。Railway 额度已耗尽；本方案提供一次有明确结束时间的临时验收窗口，不是长期 SaaS 托管，也不迁移或删除旧云数据。

## 运行方式

1. 仓库分支 ui/dark-glass-workspace 完成全量 CI，草稿 PR 不合并。
2. 由仓库拥有者为同仓库 PR 添加 crm-online-preview 标签，触发 Temporary online CRM acceptance。不会在每次代码提交时自动开启公网服务；重开需先移除再添加该标签。
3. GitHub 托管运行器构建现有 Java 21 / Vue 应用，启动独立 PostgreSQL 18、仅内网可访问的 HTTPS 对象存储，生成新的测试账号口令和密钥。
4. Cloudflare Quick Tunnel 只连接应用的本机 8080 端口，提供随机 HTTPS 主机名；数据库和对象存储不开放公网端口。cloudflared 固定 2026.10.5，下载后校验 SHA-256 e1bc0cf084fd9e590554fe769a86b1db46701c3f847a43d902f7b974a4e16298。
5. 禁用隔离测试特权，开启 Secure / HttpOnly Cookie，保持 CSRF、租户权限和 AI 总开关限制。公网逐项检查实际版本、页面资源、登录、跨租户拒绝、平台权限和真实中文报价 PDF。
6. 生成 review-readiness 报告和 review-access 文件；后者包含本次应用入口、结束时间、应用账号和 RSA-OAEP-SHA256 加密口令，不包含明文口令、数据库、对象存储或加密密钥。公钥随源码分发，私钥由交付者单独保管，口令解密后仅通过私下渠道交付。构建产物保留一天，不依赖仓库私有性来保护口令。
7. 公布入口后约两小时内持续提供验收，页面展示精确截止时间。正常截止、失败或取消时只关闭该次隧道和测试栈，运行器销毁后测试数据不保留。最终 GitHub job 仍在运行是保持验收服务所需，READY 报告表示验收就绪；不得把它说成任务已完成或永久发布。

## 适用范围

只使用虚构测试资料，不发送邮件、不联系客户、不接入真实 AI Key、不进行真实收付款。可查看并操作企业端与平台端，所有业务行为均限于新测试库。原环境的数据、备份、密钥版本和发布归档保持原样。

本次使用已有包含的验收运行额度，不开通新的付费计划或改变账号账单设置。需人工检查可用额度后再重开。Quick Tunnel 没有可用性保证，随机域名会变化；长期稳定域名、持久数据和备份需要单独落实托管方案。
