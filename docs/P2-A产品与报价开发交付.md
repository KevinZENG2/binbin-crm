# P2-A 产品与报价开发交付

版本 v0.7，2026-10-13。按你的最新指令提前开始 P2-A 云测试开发；正式邮件、独立密钥交接和真实客户试点仍需完成后再进入正式试运营。

## 功能与入口

真实客户企业端：https://crm-java-api-crm-test.up.railway.app/?account=owner 。登录、选择企业后，顶部打开「产品目录」或「报价」。客户中心每条记录的「报价」按钮可筛选该客户的报价。

平台运营端供产品方开通企业、套餐、续费、账号及平台运维使用。产品、报价属于客户企业销售业务，平台运营账号不自动取得这些资料权限。流程演示端保持浏览器本地虚构资料；P2-A 在真实客户企业端体验。

|功能|操作方式|规则|
|---|---|---|
|产品 / 服务目录|产品目录 → 新增产品 / 服务|编码企业内唯一，维护类型、单位、人民币含税单价、说明和启用状态；停用保留记录|
|报价草稿|报价 → 新建报价|选择有写权限的客户，可关联同一客户下有协作权限的商机；填写主题、有效期、说明和明细|
|报价明细|搜索启用产品 → 添加一行|最多 100 行；数量最多 4 位小数、单价精确到分、折扣精确到 0.01%；行说明最多 300 字|
|保存与修改|保存草稿 / 编辑草稿|服务器重算金额，版本冲突要求刷新；创建后客户和商机固定，需更换时新建报价|
|提交与撤回|查看 / 版本 → 提交报价 / 撤回草稿|提交后锁定明细并显示待审批；可撤回修改，产生新版本。当前提交不代表批准|
|作废|查看 / 版本 → 填原因 → 作废报价|作废不可再提交或编辑，原记录与版本保留|
|历史版本|查看 / 版本 → 查看 vN|每次创建、修改、提交、撤回、作废保存不可修改的完整快照，按页查看历史|
|PDF|查看当前或历史版本 → 下载当前查看版本 PDF|导出所选版本，嵌入中文字体，自动分页、重复明细表头和页码；仍检查当前资料访问权限|

报价数量须大于零且不超过 100 万；单价、行金额和整份总额上限为 100000000000 分（人民币 10 亿元）。零元或 100% 折扣可以保存草稿，提交要求总额大于零且有效期未过。价格为含税价，本期不另计算增值税、外币、汇率或价目表税率。

每行含税金额 = 数量 × 含税单价（分）×（10000－折扣基点）÷10000，最后四舍五入到整数分；整份金额为已经舍入的各行金额之和。例如 3.3333 项、19.99 元、优惠 12.50%，行金额为 58.30 元。折扣输入 10 表示减价 10%。

产品编码、名称、单位、单价以及企业、客户、报价人和商机名称保存快照。目录更名、改价或停用不会改写既有报价或历史版本；停用的原报价行可以保留继续修改数量、折扣和报价说明，新增行必须选择启用产品。

## 身份与权限

客户管理员在「企业管理 → 角色权限」分别配置读取目录、维护目录、读取报价、管理报价和导出报价 PDF。报价记录范围仍按各角色的全部 / 部门 / 自己范围合并读写权限，并同时校验关联客户与商机。客户共享不自动共享报价；权限撤销后当前报价、历史版本及 PDF 均重新受限。

|角色|默认能力|
|---|---|
|企业管理员（单独角色）|管理本企业组织与权限；不自动获得产品 / 报价业务权限|
|销售经理|维护目录、管理权限范围内团队报价、导出 PDF|
|销售|读取目录、管理自己权限范围内报价、导出 PDF|
|只读成员|读取获准目录及报价，不写入、不导出 PDF|
|产品方平台运营|管理客户企业和平台，不自动读取产品、报价或 PDF|

`owner` 体验账号同时有企业管理员和销售经理角色。企业到期允许受控读取和已有权限内导出，拒绝商业写入。暂停企业、支持授权、无企业上下文和未完成首次改密均沿用现有控制。

## 数据与实现

新增 Flyway V6：`crm_product`、`crm_quote_counter`、`crm_quote`、`crm_quote_line`、`crm_quote_revision`。所有新增表强制租户 RLS，运行账号无超级用户 / BYPASSRLS 权限；关联客户、商机、产品和成员使用含企业 ID 的外键。V6 后共 38 张公开表、22 张强制 RLS 表、6 个迁移版本。

每企业每年单独分配报价编号，使用锁定计数器与唯一约束保护并发编号。创建及状态动作具有幂等请求，编辑采用版本校验。报价头、明细、版本和审计在同一事务提交；模拟明细入库异常时必须全部回滚。运行账号仅能新增 / 读取报价历史，不能修改或删除版本。

人民币金额使用整数分；服务器使用 BigDecimal 数量和明确舍入，前端预览用 BigInt 定点运算。历史 PDF 从数据库保存的指定版本渲染，输出不会混入最新价目。

PDF 使用 Apache PDFBox 3.0.8，中文字体由固定 Noto CJK 源提交转换为固定字重实例，并校验 SHA-256。字体为独立受控系统资源，私有桶中按摘要命名，API 缓存校验后的字体。出处、生成参数和 OFL 原文见 `server/ops/assets/`。常见中文、数字和标点已验证；未覆盖字符返回明确提示，不生成缺字文件。单实例同时生成一份 PDF，繁忙时返回稍后重试。

备份 / 恢复同时精确支持 V5 与 V6 的完整表集合，校验强制 RLS、表属主和全部迁移成功；拒绝未知迁移、缺失表、未受保护表和不正确属主。V6 独立恢复还比较 5 张产品报价表的内容摘要。保留规则继续为 30 天、至少最近 3 份成功快照；每日北京时间 02:00 计划保持。

字体属于可复现的公共授权系统依赖，业务快照包括数据库和客户附件。换桶恢复时应通过固定字体发布脚本重建同摘要字体对象，不能将字体与客户附件混为数据保留对象。

v0.7 主应用部署成功，Flyway V6 已生效，初始化种子保持关闭。本期 P0～P1-D 回归 437 项和独立 P2-A 验收 88 项分别通过；发布后 74 项 HTTPS 只读检查通过。原账号密码保持有效，页面三个资源与构建摘要一致。发布前后 owner 当前企业可读取的客户、联系人、线索、商机、待办、跟进六类资料数量与摘要一致；这项检查限于该账号可读范围，不是全库备份。

本地 Java 37 项全部通过，云构建 36 项通过 / 1 项字体测试跳过，实际隔离 API 的 PDF 生成补充通过。领域测试 19 项、金额预览例子 8 项、运维测试 17 项及 TypeScript 构建通过。原有备份仍可用；V6 隔离快照恢复核对 38 表、257 行、22 张 RLS 表、6 次迁移和 1 个非空附件，产品与报价 5 张表内容摘要一致。临时测试对象与凭据已清理，两个验收服务均无运行进程。升级备份代码后的首次真实每日任务尚待观察，不能将隔离恢复当作原预览 V6 定时备份已执行。

本期 PDF 已生成一份短报价和一份 6 页长报价，检查全部渲染页的中文、表格、合计、说明和页码，确认无遮挡。浏览器视觉 / 鼠标端到端、手机真实设备体验和性能压测未执行；接口并发检查不等于压测。

## 下一步

P2-B 接入指定审批人、审批权限、批准 / 驳回及审批记录，禁止提交人自审，审批绑定报价版本和金额快照，修改后重新提交。合同与回款在 P2-C / P2-D 实现，CRM SaaS 订阅收款仍使用现有模块。

P1-D 运营待办仍保留：真实发信域名与邮箱核验、独立密钥交接、真实客户资料和试点验收、异地副本与外部告警。当前没有自动发报价邮件、电子签章、合同、到账登记或在线支付。
