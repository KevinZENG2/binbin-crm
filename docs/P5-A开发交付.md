# P5-A 业务底座与增长活动开发交付

版本：v0.14.0  
交付日期：2026-10-16  
状态：代码、数据库迁移、客户企业端与产品预览均已上线

## 1. 本阶段完成内容

### 产品经营资料

- 产品增加成本、税率和分类字段，保留原有 SKU、类型、单位、售价和启停状态。
- 产品列表增加毛利率、已签销售数量和已签销售金额。
- 已签指标只统计已签署、履行中或已终止合同关联的报价明细，不计草稿和未批准报价。

### 组织成员业务档案

- 成员增加员工工号、岗位、销售区域和服务状态。
- 服务状态支持“可服务、忙碌、离岗”，为后续服务工单派工提供基础数据。
- 旧接口未提交新增字段时继续兼容；编辑旧成员不会清空已有业务档案。

### 销售资源规则

- 企业管理员可按成员设置线索保有量、客户保有量、超限处理方式和未跟进判定天数。
- 超限处理支持“阻止分配”和“允许并预警”。
- 新增、转交线索或客户时实时校验规则，并用数据库行锁避免并发绕过。
- 预警记录可在企业管理页面查看并标记为已处理。

### 营销活动与 ROI

- 营销活动增加获客渠道、预算、计划开始日期和计划结束日期。
- 活动报表增加归因线索、归因客户、已签金额、确认回款和 ROI。
- 归因基于活动目标中的联系人所属客户，以及已经转换的线索所关联客户。
- 保留“营销活动”原名称，不引入外部产品的页面结构或专有交互。

### 数据与安全

- 新增 V18 数据库迁移，升级产品、成员和营销活动字段。
- 新增销售资源规则表和资源预警表。
- 两张新表均启用并强制 PostgreSQL 行级安全，运行账号与迁移账号继续分离。
- 版本冲突、企业隔离、订阅到期只读和支持授权限制继续生效。

## 2. 操作入口

| 功能 | 使用角色 | 左侧导航入口 | 主要操作 |
|---|---|---|---|
| 产品成本与毛利 | 有产品权限的销售、经理 | 交易与交付 → 产品目录 | 新增/编辑产品，查看毛利与销售指标 |
| 成员业务档案 | 企业管理员 | 企业管理 → 组织成员 | 维护工号、岗位、区域和服务状态 |
| 保有量和超限规则 | 企业管理员 | 企业管理 → 销售资源规则 | 设置成员额度、超限策略和未跟进天数 |
| 营销活动 ROI | 有营销权限的销售、经理 | 服务与增长 → 营销活动 | 维护活动渠道和周期，查看归因与 ROI |
