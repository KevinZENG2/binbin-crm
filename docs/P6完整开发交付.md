# P6：订单、财务、售后与业绩协同

版本 v0.19.0。本轮继续 P6-A，新增 P6-B、P6-C、P6-D；客户企业端沿用左侧导航与深色玻璃主题。

## 功能与操作入口

| 范围 | 左侧入口 | 操作路径 |
|---|---|---|
| P6-A 销售订单 | 交易与交付 → 销售订单 | 批准报价 → 订单草稿 → 确认 → 累计履约 → 建立合同。订单详情显示净已开票、未开票、净已到账和未到账。 |
| P6-B 开票 | 财务协同 → 开票协同 | 选择已签合同，填写抬头、税号和金额；申请人提交，另一位获准销售经理审批，再登记实际发票。支持分次申请、部分红冲和操作历史。 |
| P6-B 回款 | 交易与交付 → 回款管理 | 登记时可选资金账户；另一位获准销售经理确认后生成收入流水，部分冲正生成对应负向流水。 |
| P6-B 支出 | 财务协同 → 支出管理 | 登记付款账户、收款方、类别、日期、凭证和金额；独立财务复核人确认后生成支出流水，可填写原因全额冲正。 |
| P6-B 台账 | 财务协同 → 资金台账 | 全企业财务复核权限的销售经理维护人民币账户、期初余额和启停状态；查看按业务日期排列的流水及逐笔余额。 |
| P6-C 售后 | 服务与增长 → 服务工单 / 客诉工单 | 受理后派给在岗人员，由被派工人接单；支持转派、公开回复、内部记录、等待客户、恢复、解决、关闭与重开。 |
| P6-C SLA 与评价 | 工单详情；服务与增长 → 服务统计 | 维护自然时间 SLA、暂停等待和升级通知；完成后生成7天一次性评价链接，客户填写1至5分和建议；查看人员服务耗时与满意度。 |
| P6-D 目标 | 业绩与协作 → 业绩目标 | 销售主管设置部门或个人年度/月度目标，按可见范围内已确认净到账统计完成率；月度拆分合计不能超过已有年度目标。 |
| P6-D 提成 | 业绩与协作 → 提成核算 | 企业主管设置累进阶梯规则；试算 → 独立复核 → 月结后锁定。锁定保留原金额，仅可追加有原因的调整。 |
| P6-D 周报 | 业绩与协作 → 销售周报 | 本人填写周一开始的结构化周报 → 提交 → 主管批准或退回；已批准周报不能覆盖。 |

## 权限与业务口径

- 新模块复用现有合同、回款和工单权限及记录范围。技术管理员、平台运营、只读支持授权不因管理身份获得企业财务或业绩权限；具体岗位角色扩展仍属于 P7-C。
- 账户全量余额与支出复核要求全企业合同读取范围及回款确认权限；销售只能看有权查看合同的开票资料、本人登记的支出及本人提成；只读分析角色不会因合同全量读取权限获得他人提成。审核与登记必须为不同登录用户。
- 开票申请草稿、待审核和已批准申请均占用合同额度；实际发票按已开票减红冲计算。红冲金额不能超过未冲余额。退回的申请可以作废后重建；合同受控变更不能降至已占用开票额度以下。
- 财务使用整数分、人民币单币种。台账记录业务事实，不调用银行、税务开票或支付渠道；期初金额仅在创建账户时登记。既有未归集回款单独显示，不自动分摊到新账户。
- 提成采用超额累进阶梯，每档只计算对应区间；最终按分四舍五入。业绩和提成的基础为期间确认到账减期间冲正，业务归属按合同负责人。负净到账的当期提成按0试算，跨期已锁定差异由主管追加调整。
- 试算保留规则版本与快照、回款来源摘要。回款或可见范围变化后，原复核/锁定会被拒绝，需重算。复核人与试算人分离，且不能复核本人提成；月份结束后才可锁定。
- 工单转派不重置 SLA 截止时间。等待暂停时长从服务耗时中扣除；响应耗时在首次公开回复时固定。统计按工单创建日期与当前服务轮次计算。
- 客户评价链接只返回工单编号、有效期和是否提交，不公开内部描述与处理记录。令牌仅存哈希；新链接撤销旧链接；重开工单使旧轮次链接失效。

## 数据与接口

- Flyway V23：资金账户、不可改写流水、开票与红冲、支出及财务事件；回款增加可选账户外键。
- V24：派工/接单时间、SLA有效耗时、服务评价；既有企业补齐服务和客诉类型，新企业默认初始化。
- V25：年度/月度目标、阶梯规则、提成核算、调整、结构化周报及业绩事件。
- 新增13张表均强制租户RLS，迁移所有者与运行账号分离。流水、红冲、调整和事件表运行账号只具备读取/新增权限。
- `/api/v1/finance/*`、`/api/v1/service/tickets/*`、`/api/v1/service/statistics`、`/api/v1/performance/*` 为内部登录接口；写入检查CSRF、企业状态、订阅和版本，单据创建/流转支持请求幂等。
- `/api/v1/service-feedback/{token}` 为客户持有一次性邀请令牌时使用的评价接口，不接受内部CRM身份作为授权。
- 备份校验扩展为精确支持 V5—V25，拒绝未知迁移、缺表或非强制RLS。

## 验证与上线

验收脚本 `server/test-support/verify_p6_api.py` 仅允许本机隔离环境与虚构账号，不得直接对预览或客户业务数据库运行。覆盖订单、合同、回款与冲正、台账、开票与红冲、目标、阶梯提成与锁定、周报、派工接单、SLA暂停、评价和企业隔离。GitHub CI 使用一次性 PostgreSQL 18 服务执行该脚本，结果以当次 CI 和部署日志为准。
