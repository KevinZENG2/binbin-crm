# 彬彬 CRM · P7-A 经营分析云预览版 v0.20.0

面向多家客户企业出租使用的多租户 CRM。当前交付是 Railway 云预览，不部署到用户自有服务器；源码同步至私有 GitHub 仓库。

## 产品入口与使用人

|入口|主要使用人|用途|
|---|---|---|
|客户企业端 `?account=owner`|购买 CRM 的企业管理员、销售、客服|客户、销售、报价、合同、回款、服务、营销、行业配置、客户门户和 AI 助手|
|产品方平台后台 `?account=platform-operator`|CRM 产品方运营人员|开通企业、配置套餐、功能权益、人工订阅订单、续费、支持访问和平台运维|
|外部客户门户 `?portal=1`|客户企业所服务的外部联系人|查看本客户的报价、合同、到账记录，提交与跟踪工单，浏览已发布知识|
|流程演示端 `?mode=demo`|销售演示、评审人员|不连接真实业务库的交互演示|

主预览地址：<https://crm-java-api-crm-test.up.railway.app>。账号链接只预填用户名，密码、令牌、AI 密钥和存储凭据均不进入源码或前端。

## P0—P7-A 功能范围

- P0：真实登录、会话、CSRF、多企业工作区、PostgreSQL、租户强制 RLS。
- P1：企业 / 套餐 / 部门 / 成员 / 角色、客户权限与共享转交、附件、导入导出、提醒、恢复、审计、备份和运维。
- P2：产品目录、报价与审批、合同、收款计划、回款确认 / 冲正和对账。
- P3：服务工单与 SLA、知识库、营销活动、签名 API、Webhook 和可靠投递队列。
- P4-A：行业模板、自定义字段、标签、阶段显示、编号和审批配置。
- P4-B：与内部账号隔离的客户门户身份、客户级数据边界、门户工单及知识库。
- P4-C：客户摘要、商机辅导、工单回复三类 AI 任务；角色权限、套餐额度、幂等、脱敏上下文、反馈和运行审计。
- P4-D：套餐功能权益、企业用量、MRR / 到期概览、人工订阅订单、收款确认后一次性续期及全程审计。
- P5-A～C：销售基础资料、资源池、客户 360° 档案与互动协同。
- P5-D：商机产品明细、阶段准入、加权预测、报价折扣与毛利底线。详见 [P5-D 开发交付](docs/P5-D开发交付.md)。
- P6-A：销售订单、报价转换、履约数量与订单关联合同。
- P6-B～D：开票、资金台账与支出，售后派工/接单/评价，业绩目标、阶梯提成与结构化周报。详见 [P6 完整开发交付](docs/P6完整开发交付.md)。
- P7-A：经营指挥台、11 个分析主题、日期/负责人/部门/地区/行业筛选、图表下钻与受控 CSV 导出。详见 [P7-A 开发交付](docs/P7-A经营分析开发交付.md)。

P4-D 当前是“人工收款模式”，不会调用支付机构或自动扣款。确认订阅订单收款会在一个数据库事务中变更套餐并延长订阅；重复确认不会重复续期。

## AI 接入边界

AI 使用 OpenAI-compatible Chat Completions 协议，可连接支持该协议的供应商。默认 `CRM_AI_ENABLED=false`，没有密钥时不会发起外部请求或产生费用。

服务端只发送当前成员原本有权读取、且用户明确确认的业务白名单字段。联系方式、统一社会信用代码、账号密钥和附件不会发送；数据库不保存原始提示词或完整业务记录，只保存提示摘要哈希、脱敏上下文预览、结果、令牌计数、状态和反馈。业务记录中的文字始终按不可信数据处理，不能覆盖系统指令。

启用时通过环境变量配置：

```text
CRM_AI_ENABLED=true
CRM_AI_PROVIDER=OPENAI_COMPATIBLE
CRM_AI_BASE_URL=https://provider.example/v1
CRM_AI_API_KEY=...
CRM_AI_MODEL=...
```

## 技术与安全基线

- Vue 3 / TypeScript / Vite。
- Java 21 / Spring Boot 3.5 / JDBC。
- PostgreSQL 18，Flyway V1—V25；业务表使用独立迁移所有者与非 BYPASSRLS 运行账号。
- 企业业务表强制 RLS；平台控制面接口额外校验平台运营身份。
- 密码 BCrypt、会话仅 HttpOnly Cookie、写请求 CSRF 与工作区一致性校验。
- 外部客户门户使用独立 Cookie、会话、限流和审计，不接受内部 CRM 身份。
- AI 外呼只允许由服务端环境变量配置的 HTTPS 地址；用户不能提交供应商 URL 或密钥。
- 备份工具精确识别 V5—V25，并验证表集合、迁移、强制 RLS、内容摘要和一次性恢复。

## 当前边界与下一步

本版本不包含自动支付、电子签章、短信渠道、AI 知识检索向量库、任意自定义角色或移动原生客户端。上线前还需配置正式邮件、决定 AI 供应商与数据处理协议、完成首批客户试点、压测、外部告警和生产切流演练。

P4 的范围、操作入口、验收口径和下一阶段建议见 `docs/P4完整开发交付.md`。
