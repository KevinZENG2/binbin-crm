# 彬彬 CRM · P2-B 云测试版本 v0.8

用户自有、多家企业订阅使用的 CRM，按 P0、P1-A～P1-D、P2～P4 分阶段开发；当前使用云预览，不部署到用户服务器。

- 真实 CRM：https://crm-java-api-crm-test.up.railway.app
- 客户企业管理员体验：https://crm-java-api-crm-test.up.railway.app/?account=owner
- 产品方平台运营：https://crm-java-api-crm-test.up.railway.app/?account=platform-operator
- 完整流程演示：https://binbin-crm-preview.zengb-12.chatgpt.site

真实 CRM 使用原测试密码。owner 选择企业后进入完整工作台，拥有企业管理员和销售经理角色；platform-operator 用于产品方开通企业、套餐、状态、续费与平台运维，不自动读取企业业务。账号链接只预填用户名。密码、令牌和存储凭据不写入源码或前端。演示站点保留浏览器本地数据，与服务器业务数据分开。

## P1-D 已有功能

|功能|操作入口|
|---|---|
|权限范围内的日期报表、阶段分布、成交和待办统计|企业工作台 → 数据报表|
|客户 CSV 模板、预校验、错误行、有效行提交和批次历史|企业工作台 → 导入导出 → 客户导入|
|客户、联系人、线索、商机、待办和跟进六类 CSV|企业工作台 → 导入导出 → 数据导出|
|真实私有 S3 上传 / 下载 / 删除，企业容量和清理重试|企业工作台 → 附件，或客户行 → 附件|
|每五分钟检查的个人到期 / 逾期待办提醒|企业工作台 → 站内提醒|
|报表、导出、导入及附件五项独立权限|企业工作台 → 角色权限|
|附件已用量与上限 / 平台配置容量|套餐订阅 / 平台套餐管理|
|数据库与存储健康、资源及后台任务记录|平台运营 → 平台运维|
|核验邮箱绑定和密码找回实现|平台运营 → 登录账号；正式 SMTP 未配置时找回关闭|

单文件最多 5MB，支持 PNG / JPEG / PDF / UTF-8 TXT / CSV；客户导入最多 500 行、512KB；单次导出最多 5000 条。报表口径与权限边界详见本轮交付文档。

P0～P1-C 继续保留：真实登录及多企业上下文，企业 / 套餐 / 部门成员 / 角色，额度与人工续费，只读支持和审计，客户共享转交，联系人与线索原子转换，商机看板 / 阶段历史 / 成交丢单，跟进及待办完成重开，首次改密和会话撤销。新增附件窗口沿用居中、限高、内部滚动的弹窗布局。

## 实现和验证

Vue 3 / TypeScript、Java 21 / Spring Boot 3.5.16、原生 PostgreSQL 18.6，当前 Flyway V1～V7，40 张公开表、24 张企业范围表强制 RLS，运行与迁移账号分离。未采用 SQLite。

前端执行 npm ci、npm test、npm run build；后端执行 mvn -f server/pom.xml verify。环境变量占位说明见 server/.env.example。初始化需独立 runtime / migrator 角色；种子数据仅允许 development / test 且提供强测试密码，现有预览保持关闭初始化。

P1-D 历史交付：Java 32 项、浏览器本地领域 19 项和 Vue / TypeScript 构建通过。P0 / P1-A / P1-B / P1-C 316 项回归及新增 P1-D 验收使用一次性原生 PostgreSQL 18.6 和虚构资料。历史完整结果见 docs/P1-D完整验收结果.json；原预览仅做正常登录、自己的企业选择、GET 和退出，不用于业务写入验收。没有浏览器视觉 / 鼠标端到端或性能压测。

Dockerfile 提供 Vue、Java 校验和非 root JRE 镜像；Dockerfile.backup 与 .github/workflows/verify-and-container.yml 已准备。正式 GitHub / 容器注册表尚未连接，在线流水线未运行；当前云测试继续使用校验源码包和官方 Maven / Java 21 镜像构建。源码和文档保存于现有项目关联 Git。

## P2-B 报价审批

客户企业端新增「报价审批」。报价提交时指定另一位有资料读取权限的有效销售经理；批准 / 驳回绑定报价版本和金额，禁止提交人或报价人自审。撤回取消原审批，批准后修改需填原因转回草稿再重新提交；驳回原因、审批与版本历史保留。角色权限新增独立报价审批开关，审批可与报价编辑权限分离。
